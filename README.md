## Tech Stacks used in Past Projects

- **[Lottom](https://github.com/siru-ink/lottom)** uses Rust, the Axum web framework, and PostgreSQL to create a simple multi-user shopping list tracker with shareable lists.
- **[Wahlen Web](https://github.com/siru-ink/wahlen-web)** uses Go lang, Gin web framework, and Sqlite3 to create an at-rest-encrypted voting platform for club elections.
- **[Memnosyne-Journal](https://github.com/siru-ink/mnemosyne-journal)** used Python, TKinter for GUI, and basic filesystem IO to provide a local, encrypted journal storage.

All the code for the projects is mirrored from my own Git Forge located at [code.siru.ink](https://code.siru.ink/).
